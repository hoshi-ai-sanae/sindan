# あなたらしい進み方がわかる｜星の強み診断

Lumiereの公式LINE登録プレゼント。最初に「あなたの星座は何座ですか？」と尋ね、選んだ太陽星座に対応する強み・進み方・行動のヒント・メッセージを表示します。質問を採点する方式ではなく、12星座の固定文を読むアプリです。

## 使うページ

- `index.html`：配布用アプリ
- `results.html`：12星座の結果文一覧。アプリと同じ`results.js`から表示します。
- `results.js`：星座・守護星・結果文。文章の変更はこのファイルで行います。
- `app.js`：星座の選択・結果表示・選び直し
- `style.css`：PCとスマートフォンの表示

ビルドやインストールは不要です。外部ライブラリ、外部フォント、APIキーは使いません。入力欄は星座の選択だけです。外部への送信、アクセス解析、Cookie、localStorage、sessionStorageによる保存は行いません。選択状態はページを開いている間だけ保持し、再読み込みで初期画面に戻ります。

## STEP1の参照元

元アプリ「星AI起業ナビ」の次の内容を読み取り、新しい文章にまとめました。元ファイルを新アプリへコピーしていません。

- `docs/星×AI起業ナビ_設計書.md`：「世界を見る視点」「人生における前提」
- `src/natal-analysis.js`：`WORLD_VIEW`、`PREMISES`、`RULERS`
- `src/stage1-sign-guides.js`：12星座の太陽星座向けの説明を中心に、行動のヒントを参照

参照元の「あなたの強み」は月星座を使う設計ですが、今回のアプリは依頼に合わせて太陽星座と守護星だけを使います。月星座による個別判定を再現したものではありません。

独立した詳しい「守護星の特性」一覧は参照元にありません。守護星に対応する前提と各星座の説明をもとに、短い説明へ編集しています。「不足している」は自分の欠点と断定せず、好奇心や役立つ工夫につなげ、「幸運である」は成功の保証とせず、希望や可能性を広げるヒントにしています。

## GitHub Pages

リポジトリ：`hoshi-ai-sanae/sindan`。公開するファイルはこのフォルダの内容だけです。他のアプリや顧客管理ファイル、`.env`をアップロードしないでください。

GitHubのSettings → Pagesで、mainブランチのルートを公開対象にします。CSS・JavaScriptは相対パスなので、リポジトリ名の付いたGitHub Pagesでも動きます。

LINEの自動返信・配布設定は含みません。公開後のアプリURLをLINEの配布文に設定してください。
